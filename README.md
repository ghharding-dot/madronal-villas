# Madroñal Villas

Standalone website rebuild for Villa Candela and Villa Lámpara in El Madroñal, Benahavís, Marbella.

## Deployment

This repository is structured as a simple static website and can be imported directly into Vercel.

- Framework preset: Other
- Root directory: repository root
- Build command: leave blank
- Output directory: leave blank

## Current status

The site includes the initial responsive homepage, enquiry flow, location, services and clearly labelled image placeholders. Final photography and verified villa details will be added before launch.
